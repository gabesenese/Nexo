# Observations: what they do, and where Nexo can win

The scorecard says who answers correctly. This file records everything else a competitor does
that a score cannot show. Fill one section per product while you run the test, in the moment,
not from memory afterwards. Quote or screenshot specifics. "Feels slow" is not an observation;
"first answer took about 9 seconds, no typing indicator" is.

For each finding, tag it **[copy]** (they do it well, we should match it), **[beat]** (they do it
badly, we can be clearly better) or **[ignore]** (differs, but does not matter to buyers).
